## 建議學習順序

```text
會員 Model
    ↓
註冊與密碼雜湊
    ↓
登入與 JWT
    ↓
授權保護 API
    ↓
Vue 登入狀態與會員畫面
```

正式開始前會先決定採用 ASP.NET Core Identity，或以較精簡的 JWT 流程教學。兩者不會同時建立，避免重複的會員邏輯。
